# ก๊าบก๊าบคาเฟ่ · MOOD CUP

แอปสะสมมู้ดประจำวัน: เข้าร้าน เจอบาริสต้าน้องเป็ดแบบสุ่ม (5 ตัวตอนเปิดตัว: เป๊ะ เบอร์รี่ มอส โมโม่ บ็อบบี้) ชงเครื่องดื่มเองทีละขั้น แล้วเก็บเป็นแสตมป์บนปฏิทินรายเดือน พร้อมสรุปเดือนและการ์ด PNG สำหรับแชร์

**Phase 1 (branch `app-phase1`):** แขก 5 ตัวปลดล็อกตามแสตมป์สะสม 3/7/14/30/60 (ถาวร) + เมนูลับแพนด้าแดง · ของตกแต่งโบนัสจากสตรีค (ขาดวันไม่เสียอะไร) · "คิดถึงนะ" เมื่อกลับมา · เตือนรายวัน (ถามหลังแก้วแรก เลือกเวลา/ปิดได้) · แสงตามเวลาจริง + ป้ายใกล้ปิดร้านหลัง 22:00 + ดีแคฟ · "เหมือนเดิมไหม?" · ระบบวันเทศกาล (วันจริง ชนกันแสดงทั้งคู่ ฤดูตามซีกโลก; ยังไม่มีภาพเทศกาล) · สำรอง/นำเข้าข้อมูล · ไอคอนและหน้าเปิดแอป · นโยบายความเป็นส่วนตัว

- Static web project, framework-free (HTML/CSS/vanilla JS) · ไม่มี build step · ข้อมูลเก็บในเครื่อง (localStorage) เท่านั้น
- ฟีเจอร์ของเครื่อง (เก็บข้อมูล แจ้งเตือน สั่น แชร์ ไฟล์) อยู่หลัง adapter ใน `platform.js` เพื่อให้แอป iOS เปลี่ยนเป็น native ได้ — ดู **[HANDOFF.md](HANDOFF.md)**
- ภาพประกอบ: ภาพใหม่ตั้งแต่ Phase 1 สร้างด้วย **Grok** (ไม่ใช้ agy แล้ว) ในสไตล์ดินสอสีเดิมของร้าน — รายละเอียดใน [CREDITS.md](CREDITS.md)
- ไม่มีโฆษณา ไม่มีการซื้อในแอป ไม่มีกล่องสุ่ม ไม่มีการติดตาม — [PRIVACY.md](PRIVACY.md)
