# ก๊าบก๊าบคาเฟ่ · MOOD CUP

แอปสะสมมู้ดประจำวัน: เข้าร้าน เจอบาริสต้าน้องเป็ดแบบสุ่ม (12 ตัว) ชงเครื่องดื่มเองทีละขั้น แล้วเก็บเป็นแสตมป์บนปฏิทินรายเดือน พร้อมสรุปเดือนและการ์ด PNG สำหรับแชร์

- Static site (HTML/CSS/JS) · ข้อมูลเก็บใน localStorage
- ภาพประกอบทั้งหมดวาดด้วย **agy (Google Antigravity CLI)** อ้างอิงตัวละคร Duckling Sort
- UI เส้นวาดมือ: SVG filters
